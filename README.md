# Recent chats

Плагин **«Последние чаты»** для exteraLess.

Проведите вверх по **⋮ справа в строке ввода**. **Со скрепки свайп тоже работает.** Появится список недавно открытых вами чатов: давние сверху, свежие снизу. Нажатие на строку переключает чат.

- Обычное нажатие на ⋮ открывает штатное меню, на скрепку — вложения.
- Панель занимает всю ширину окна и прилегает к строке ввода, в том числе над открытой клавиатурой.
- Длинный список раскрывается до нижней границы строки состояния. Чтобы опустить самые давние чаты для одной руки, прокрутите до начала списка и проведите вниз ещё раз. Список плавно следует за пальцем и остаётся на выбранной высоте после отпускания; опускание можно продолжить следующим жестом. Над опущенным списком снова виден чат; нажатие в этой области закрывает панель.
- Окно, фотографии и заглушки аватарок — прямоугольные, без скруглений.
- Справа показаны штатные значки новых событий, как в списке чатов клиента: красное сердце реакций, синий **@** упоминаний и пузырь сообщения с числом непрочитанных, в таком порядке. Реакции и упоминания отображаются значками без числа; их количество сохранено в описании для доступности. Нулевые индикаторы скрыты; отметка «не прочитано» без числа показана точкой в пузыре. У отключённых уведомлений счётчик сообщений серый.
- Индикаторы берутся из состояния чатов клиента и обновляются, пока список открыт. Цвета соответствуют текущей теме; используются ресурсы клиента для сердца и @, а также его контур пузыря сообщения.
- В форумах счётчики учитывают события по темам, как штатный список чатов: число в пузыре показывает количество тем с непрочитанными сообщениями, сердце — наличие непрочитанных реакций в темах. Цвет счётчика учитывает уведомления отдельных тем. При загрузке и обновлении тем индикаторы открытой панели обновляются.
- В настройках показан один текстовый блок с полным описанием, без строк, похожих на кнопки, и обрезанных пояснений.
- Список сразу открывается на свежих чатах, без видимой прокрутки при появлении панели. Старые записи доступны прокруткой вверх.
- Повторное посещение переносит чат вниз без дублей. Текущий чат не показывается.
- До 50 чатов сохраняются отдельно для каждого Telegram-аккаунта, включая после перезапуска приложения.
- Это история посещений с момента включения плагина, а не сортировка по времени сообщений. Темы и комментарии учитываются как посещение основного чата.

## Установка

1. Скачайте [recent_chats.plugin из последнего релиза](https://github.com/Ovolsan/Recent-chats/releases/latest/download/recent_chats.plugin).
2. Откройте файл в exteraLess и установите плагин.
3. Включите доверенный доступ и разрешения **Интерфейс**, **Чтение сообщений** и **Переписывать код приложения (hooks)**.

Если у вас установлен и включён плагин установки с GitHub, можно открыть [RAW-ссылку](https://raw.githubusercontent.com/Ovolsan/Recent-chats/main/recent_chats.plugin) в чате exteraLess: установщик предложит установку или обновление.
