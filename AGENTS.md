# Оформление Recent chats

Окно, аватарки и заглушки аватарок должны иметь прямые углы, без скруглений. Не возвращать скругления в следующих версиях. По запросу пользователя от 12 октября 2026 индикаторы новых событий повторяют штатные значки на его скриншоте: сердце реакций, круглый @ упоминаний и пузырь сообщения с числом, в таком порядке.

Список занимает всю ширину окна приложения и прилегает к строке ввода. Свайп работает при пустом и заполненном поле; обычное нажатие сохраняет действие клиента.

Свайп должен работать на обеих нижних кнопках: скрепке и отдельной ⋮ справа. Для контейнера аудио/видео жест действует только в состоянии MENU, чтобы не вмешиваться в запись.

Описание в настройках — один неинтерактивный текстовый блок с переносами строк, без отдельных строк Text с обрезаемым subtext.

Счётчики форумов берутся из TopicsController.getForumUnreadCount, как в штатном DialogCell, включая реакции по темам. Нулевые агрегаты тем не подменять устаревшими значениями общего диалога; учитывать topicsDidLoaded при обновлении открытой панели.

Первый видимый кадр панели должен сразу показывать свежие чаты внизу. Измерять и размещать список, устанавливать scrollTo до showAtLocation; не запускать отложенный fullScroll после показа окна.

Длинный список раскрывается до нижней границы строки состояния. Самые старые чаты можно опустить для одной руки дополнительным свайпом вниз после достижения начала списка. Опускание плавно следует за пальцем и сохраняет выбранное положение после отпускания, без скачка на максимальную высоту. Аватарки 36 dp, строки 48 dp; не увеличивать высоту строк при изменении иконок.
